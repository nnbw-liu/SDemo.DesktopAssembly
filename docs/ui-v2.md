# SDemo Hub v2 界面设计

> 状态：**已实现（2026-11-08）**。实现落在 `src/SDemo.Hub.App`（WPF + Blazor Hybrid，无独立 Razor 类库）；页面集中在 `Components/Main.razor`，壳级窗口/托盘/热键/WebView2 宿主在同工程。
> 关联：[requirements-v2.md](requirements-v2.md) · [hub-protocol.md](../../docs/contracts/hub-protocol.md)（已冻结）

---

## 1. 技术形态

- **WPF + Blazor Hybrid**：主窗 `MainWindow` 用 `BlazorWebView` 承载整个控制页；v1 的 `ShellPanelWindow` 已随 M5 删除。
- 页面与状态都在 `SDemo.Hub.App` 内：`Components/Main.razor` + `HubUiState.cs`（没有单独的 Razor 类库）。
- `SDemo.Hub` 只保留无 UI 的发现/注册表/连接监控/布局存储；WPF 层负责窗口、托盘、热键、WebView2 组件宿主与主题。
- 托盘仍是 WinForms `NotifyIcon`；打开/关闭主窗走 WPF。
- **桌面组件不是 BlazorWebView**：每个组件是一个独立 WPF 窗口 + `WebView2`，导航到应用提供的 URL；不复用主窗的 Blazor 运行时。组件默认跟随系统主题，Hub 详情里可对每个组件单独选 `auto/light/dark`，写入 `widgets.json` 并即时切换窗口 chrome 与页面。

```
SDemo.Hub.App.exe
 ├─ MainWindow (WPF + BlazorWebView → Components/Main.razor)
 ├─ WidgetWindow × N (WPF + WebView2 → app widget URL)
 └─ TrayService (NotifyIcon)
```

### 4.6 设置

分组卡片：

1. **外观**：主题（跟随系统/浅色/深色）。
2. **启动**：开机自启、启动时隐藏主窗。
3. **组件**：显示/隐藏全部热键、切换穿透热键、截屏隐藏、默认不抢焦点（只读说明）。
4. **应用**：已隐藏的应用（可恢复）、已确认的启动路径（可撤销）。
5. **目录**：Hub 端口（只读）、MCP 地址（复制）、`sdemo.hub.json` 路径。
6. **关于**：版本、hostApiVersion、WebView2 版本、日志目录。

### 4.7 诊断

- 顶部状态摘要：配置文件数、在线/离线/错误、WebView2 版本。
- 表格：appId、文件、状态、错误码、最近时间。
- 日志尾部 200 行（只读），复制/打开目录。
- “重新扫描”按钮。

## 5. 状态与反馈

| 状态 | 表现 |
| --- | --- |
| 首次加载 | 侧栏 + 内容骨架屏，≤300ms 不闪烁 |
| 无应用 | 空态插画 + 配置目录路径 + “复制路径” |
| 应用启动中 | 卡片按钮变 spinner + “启动中…”，禁止重复点击 |
| 连接失败 | 红色 toast + 卡片状态红点；详情显示错误码与提示 |
| 配置非法 | 概览“需要处理”+ 诊断行；不弹窗 |
| 不兼容 | 卡片徽章“不兼容”；组件不可添加 |
| 应用离线 | 组件窗口离线占位，提供“启动应用” |
| WebView2 缺失 | 全窗阻塞提示 + 修复说明（不自动下载） |
| 剪贴板成功 | 右下角 toast 1.5s |

## 6. 关键流程

### 6.1 启动应用

1. 点“启动”。
2. 首次：确认对话框显示 `executable` 全路径 + 参数；确认后记录。
3. Hub 启动进程，卡片进 `launching`。
4. 等配置更新 + `/v1/info`，成功进 `online`；超时进 `error`，提示查看日志。

### 6.2 添加组件

1. “添加组件”打开抽屉，列出在线应用与组件。
2. 多选 → “添加到桌面”。
3. Hub 为每个组件建窗口，按默认位置错开 24px。
4. 抽屉关闭，toast“已添加 2 个组件”。

### 6.3 打开主窗

- 支持：`POST mainWindow.openUrl`，失败 toast。
- 不支持：按钮禁用，tooltip“应用未声明主窗入口”。

### 6.4 应用退出

1. 配置文件变化 / 健康检查失败。
2. 卡片转离线；组件转离线占位。
3. 应用重启后自动重连并重载组件。

## 7. Blazor 结构（实际）

```
src/SDemo.Hub.App/
  _Imports.razor
  Components/
    _Imports.razor
    Main.razor              // 侧栏 + 六个页面 + 应用详情 + 设置/诊断
  wwwroot/
    index.html
    css/app.css
  HubUiState.cs             // 快照 + Changed 事件；应用/组件/设置/诊断动作
  MainWindow.cs             // 主窗 + BlazorWebView + 主题 chrome
  WidgetWindow.cs           // 组件窗：WebView2、离线占位、标题栏、吸附
  WidgetHostService.cs      // 组件生命周期、布局、热键、截屏隐藏
  TrayService.cs            // 托盘菜单
  HotkeyService.cs          // 全局热键注册
  AutostartService.cs       // 开机自启
```

- `HubUiState` 订阅注册表/监控/组件的 `Changed`，在 WPF Dispatcher 上触发 `StateHasChanged`。
- 页面不直接操作窗口；统一经 `HubUiState` / `WidgetHostService`，便于单测与错误处理。
- 复制用 WPF `Clipboard`，不依赖 JS。
- 导航：侧栏切换概览、应用、组件、目录、设置、诊断；应用卡片进入详情。

### 8.2 字体与间距

- 字体：`Segoe UI Variable`, `Microsoft YaHei UI`, sans-serif。
- 标题 20/600，页面标题 26/650，正文 14/400，辅助 12/400。
- 间距 4 / 8 / 12 / 16 / 24 / 32。
- 圆角：卡片 12，按钮 8，输入框 8。
- 阴影：`0 1px 2px rgba(15,23,42,.06)`，hover 提升到 `0 4px 12px`。
- 动效 120–180ms ease-out；尊重系统“减少动画”。

### 8.3 图标

- 优先 Segoe Fluent Icons 字体；应用图标来自 `icon`，缺失时用首字母色块。
- 状态点 8px，带 2px 外发光。

## 9. 托盘

菜单：

- 打开 SDemo Hub（粗体）
- 显示全部组件 / 隐藏全部组件
- 组件子菜单（逐组件：显示/隐藏、置顶、穿透、定位、热键提示）
- 目录地址（复制 MCP 地址）
- 设置
- 诊断
- 退出

双击托盘 = 打开 Hub。通知沿用现有气泡，仅用于启动失败/组件加载失败。

---

## 10. 可访问性

- 全键盘可达：Tab 顺序、Esc 关闭抽屉/对话框、Enter 确认。
- 焦点环 2px accent，不用纯颜色传达状态（配文字/图标）。
- 对比度 ≥ 4.5:1。
- 200% 缩放不裁切（主窗可缩放，卡片单列）。

---

## 11. 暂不做

- 组件实时缩略图预览（WebView2 截图成本高）。
- 应用内安装/更新 UI。
- 目录里手动添加 MCP。
- 多实例管理 UI。
- 自定义主题色/壁纸。
